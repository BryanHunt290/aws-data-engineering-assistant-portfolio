# Synthetic demo knowledge corpus

The seven documents in this directory were written specifically for the Data
Engineering Assistant's offline demonstration and deterministic evaluation
tests. They cover synthetic S3, Glue, Athena, IAM, PySpark, monitoring, and cost
scenarios. They do not contain customer information, private operational
records, credentials, AWS account IDs, commercial book content, or copied LLM
Zoomcamp FAQ material.

Do not replace these files with customer documents, production exports, or
other private data. Screenshots, examples, and issue reports should use this
corpus unless a separately reviewed public dataset is introduced. The corpus is
versioned with the source code and loaded in filename order for reproducibility.
