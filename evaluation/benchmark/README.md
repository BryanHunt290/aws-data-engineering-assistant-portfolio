# Synthetic retrieval benchmark

`retrieval_benchmark.json` contains 35 synthetic retrieval queries and
`llm_prompt_benchmark.json` contains synthetic fixed-context prompt cases.
Both were written specifically for offline evaluation of the Data Engineering
Assistant's CC0 demo corpus. They contain no customer data, private operational
records, commercial book content, or copied LLM Zoomcamp FAQ material.
